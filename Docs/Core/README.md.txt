# PMP - Plataforma de Manutenção Preventiva

## Descrição

O PMP é um sistema de gestão de manutenção preventiva e corretiva que organiza equipamentos, intervenções e registos operacionais num único ambiente estruturado.

---

## Objetivo

Transformar processos de manutenção em dados estruturados, rastreáveis e reutilizáveis, criando uma memória técnica permanente da organização.

---

## Funcionalidades principais

- Planeamento semanal de manutenção
- Registo diário de ocorrências
- Gestão de fichas de manutenção
- Histórico central de registos
- Associação de fotografias e documentação
- Consulta de dados operacionais

---

## Estrutura do sistema

- PMP_MASTER_CONTEXT.md → visão global
- DOMAIN_MODEL.md → modelo de dados
- BUSINESS_RULES.md → regras de negócio
- SYSTEM_ARCHITECTURE.md → arquitetura
- APPLICATION_MAP.md → ecrãs (em evolução)
- AI_IMPLEMENTATION_GUIDE.md → guia para IA
- PROJECT_INDEX.md → mapa do projeto

- START_HERE.md → ponto de entrada para qualquer IA
- PROJECT_VISION.md → visão estratégica do projeto
- PROJECT_CHANGELOG.md → histórico de alterações

---

## Organização da documentação

A documentação encontra-se organizada da seguinte forma:

Docs/

- Core/ → documentação principal do sistema.
- AI/ → documentação do Copiloto Inteligente, memória, decisões, roadmap e funcionalidades de IA.
- Screens/ → documentação funcional de cada ecrã.
- Images/ → capturas de ecrã, diagramas e imagens de apoio.

Esta organização permite que qualquer Inteligência Artificial ou programador compreenda rapidamente o projeto e saiba onde encontrar a informação necessária.
---
