# ESTRUTURA DA DOCUMENTAÇÃO

Toda a documentação do projeto encontra-se organizada da seguinte forma:

Docs/

    Core/
        README.md
        PROJECT_INDEX.md
        PMP_MASTER_CONTEXT.md
        DOMAIN_MODEL.md
        BUSINESS_RULES.md
        APPLICATION_MAP.md
        SYSTEM_ARCHITECTURE.md
        AI_IMPLEMENTATION_GUIDE.md

    AI/
        AI_COPILOT_MASTER_PROMPT.md
        AI_MEMORY.md
        AI_FEATURES.md
        AI_ROADMAP.md
        AI_DECISIONS.md

    Screens/
        Plano_Semanal.md
        Ficha_Manutencao.md
        Registos_Diarios.md
        Historico_Registos.md

Sempre que iniciares uma nova sessão:

1. Ler primeiro:
   - Docs/Core/README.md
   - Docs/Core/PROJECT_INDEX.md

2. Depois:
   - Docs/Core/PMP_MASTER_CONTEXT.md
   - Docs/Core/DOMAIN_MODEL.md
   - Docs/Core/BUSINESS_RULES.md

3. Se a tarefa envolver IA:
   - Ler toda a pasta Docs/AI/

4. Se envolver um ecrã específico:
   - Ler primeiro o respetivo ficheiro em Docs/Screens/

Nunca assumir informação sem consultar primeiro a documentação correspondente.
